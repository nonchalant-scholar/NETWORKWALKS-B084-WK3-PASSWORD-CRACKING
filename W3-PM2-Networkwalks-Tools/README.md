# W3-PM2 — Password Cracking with Networkwalks Tools

## Overview

This module documents a practical exercise in password recovery using the online tools provided by Networkwalks. The exercise involved extracting password-protection data from an instructor-provided PDF file and using the Networkwalks Password Cracker to attempt password recovery.

## Tools and Environment

| Item | Details |
|---|---|
| Operating system | Windows 11 |
| Hash extraction tool | Networkwalks Hash Calculator |
| Password recovery tool | Networkwalks Password Cracker |
| Target file | Instructor-provided practice PDF |
| Environment | Web browser |

## Practical Activities

The following activities were completed:

1. Obtained the instructor-provided password-protected PDF file.
2. Opened the Networkwalks Hash Calculator in a web browser.
3. Uploaded the protected PDF to extract its PDF hash.
4. Copied the complete extracted hash, beginning with `$pdf$`.
5. Opened the Networkwalks Password Cracker.
6. Submitted the extracted hash and initiated the password recovery process.
7. Waited for the tool to complete its attempt and display the recovered password.
8. Used the recovered password to open and verify the protected PDF.

## Learning Outcomes

- Understood the basic workflow involved in recovering passwords from protected PDF files.
- Gained practical exposure to PDF hash extraction.
- Used a browser-based password recovery tool.
- Understood why password complexity and resistance to guessing attacks are important.

## Evidence and Documentation

The `evidence/` directory contains screenshots supporting the practical activities and completion of the exercise.

Sensitive information, including recovered passwords and complete hash values, is intentionally excluded from this public repository.

## Scope and Responsible Use

The exercise was performed using an instructor-provided practice file and the tools specified in the lab instructions. The activity was limited to the assigned educational exercise.

## Disclaimer

This documentation is intended for educational purposes and independent cybersecurity learning. Password recovery techniques should only be used on files that you own or are explicitly authorized to test.
